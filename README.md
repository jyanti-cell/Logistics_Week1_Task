# Logistics Week 1 - Strategic Planning and Data Exploration

## Project Overview
This project focuses on exploring logistics delivery data and identifying factors that affect delivery time.

## Dataset
Amazon delivery dataset containing information about delivery time, traffic, weather, vehicle type, location and other delivery-related factors.

## KPIs
- On-Time Delivery Rate
- Average Delivery Time
- Average Delivery Cost
- Vehicle Utilization

## Data Science Methods
- Exploratory Data Analysis (EDA)
- Group-based analysis
- Regression
- Clustering
- Route Optimization

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code

## Analysis Performed
The Python script loads the dataset, checks missing and duplicate values, calculates basic statistics and analyzes average delivery time based on traffic, weather and vehicle type.

## Files
- `amazon_delivery_data.csv` - Dataset
- `logistics_analysis.py` - Python analysis code
- `traffic_delivery_time_graph.png` - Visualization
