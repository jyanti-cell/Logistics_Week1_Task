# Week 4 – Predictive Modeling and Optimization in Logistics Systems

## 1. Overview

This project focuses on applying predictive modeling techniques to a logistics problem.

The main objective is to predict **Delivery Time** using logistics-related features such as:

- Shipment Volume
- Transportation Cost
- Distance

The model results are also used to suggest optimization strategies for improving logistics operations.

---

## 2. Problem Definition

Delivery delays can affect customer satisfaction and operational efficiency.

In this task, a predictive model is developed to estimate the delivery time of shipments based on selected logistics features.

**Target Variable:**
- Delivery_Time

**Input Features:**
- Shipment_Volume
- Transportation_Cost
- Distance
