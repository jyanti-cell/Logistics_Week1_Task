# Logistics Data Analysis and Preprocessing

This project focuses on data exploration, cleaning, and preprocessing of a logistics delivery dataset.

## Dataset
Amazon Delivery Dataset containing delivery-related information such as:
- Agent age and rating
- Location coordinates
- Weather
- Traffic
- Vehicle
- Delivery time
- Order category

## Week 1
- Dataset exploration
- Basic statistical analysis
- KPI identification
- Delivery time analysis

## Week 2
- Missing value analysis
- Duplicate record checking
- Numerical and categorical variable identification
- Outlier detection using IQR
- Min-Max normalization
- Preprocessed dataset creation

## Tools Used
- Python
- Pandas
- Matplotlib
- GitHub

## Output
The preprocessed numerical dataset is saved as:
`preprocessed_logistics_data.csv`
