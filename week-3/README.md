# Week 3 – Advanced Data Analysis and Visualization in Logistics

## Objective
The objective of this task is to analyze logistics data using Python and create meaningful visualizations to understand delivery time, shipment volume, transportation cost, and distance.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

## Dataset
A hypothetical logistics dataset containing 20 shipment records was created.

The dataset includes:
- Shipment ID
- Delivery Time
- Shipment Volume
- Transportation Cost
- Distance

## Analysis Performed
- Dataset exploration
- Statistical summary
- Mean and median calculation
- Missing value analysis
- Correlation analysis
- Data visualization

## Visualizations
The following visualizations were created:

1. Correlation between logistics variables
2. Distance vs Transportation Cost
3. Shipment Volume by Shipment ID
4. Distribution of Delivery Time

## Key Insights
- Average delivery time is 4.6 days.
- Average shipment volume is 95.5.
- Average transportation cost is 910.
- Average distance is 45.25 km.
- Transportation cost increases with distance.
- Shipment volume, distance, transportation cost, and delivery time show strong positive relationships in the dataset.

## Recommendations
- Optimize routes to reduce transportation cost.
- Monitor high-cost and long-distance shipments.
- Plan resources for high-volume shipments.
- Monitor shipments with longer delivery times.
- Use data visualization for better logistics decision-making.
